# 책은 싸게 사는 거임 (BiblioOptima) - 프로젝트 개요

_Last updated: 2026-02-19_

## 1) 목적 (Purpose)
- 여러 권의 책을 한 번에 입력하면, 판매처/셀러/배송비를 함께 계산해 **실제 결제 총액 기준 최저 조합**을 추천한다.
- 단순 가격 나열이 아니라, 상태/배송/신뢰도까지 반영해 사용자가 바로 구매 결정을 내릴 수 있게 한다.

## 2) 동기 (Why this exists)
- 중고책은 책마다 판매처가 달라서, 사람이 수작업으로는 최저 조합 계산이 거의 불가능하다.
- 특히 배송비(묶음/개별), 품질 편차, 잘못된 책 매칭 때문에 실제 결제가 비싸지거나 실패하는 경우가 많다.
- 이 서비스는 위 문제를 자동화해 시간과 비용을 동시에 줄인다.

## 3) 현재 시스템 오버뷰 (Current Overview)
- 입력:
  - 다권 입력
  - 제목 + 괄호 메타데이터(출판사/저자/옮긴이/출간년도/ISBN)
  - 콤마(,)로 항목 확정, Enter로 줄 확정
- 데이터 소스:
  - 알라딘 Open API
  - 외부 크롤러 API (국내 판매처)
  - 아마존 원서 크롤러 API
- 핵심 로직:
  - 타이틀 매칭 + 상태 추론 + 점수화(가격/상태/배송/신뢰)
  - 다권 묶음 최적화(조합 탐색 + 배송비 정책 반영)
  - 차선책(Next Best) 후보 표시
- 결과:
  - 책별 추천 판매처
  - 다권 최저가 조합
  - 리스크/설명/대체안 표시

## 4) 지금부터의 우선순위
- 1순위: Amazon JP 일본어 원서 지원 + 한국 번역서와 연계
- 2순위: 매칭 정확도 및 응답 안정성 개선
- 3순위: 모바일 가독성/조작성 개선

## 5) 범위 정의 (In/Out)
- In (지금 할 것):
  - Amazon JP 데이터 수집 연결
  - 일본어 원서 상태/통화/배송 정보 표준화
  - 한국어 번역서와 일본어 원서 연결 규칙 추가
- Out (지금 안 할 것):
  - 모든 해외 마켓 동시 확장
  - 대규모 인프라 재설계
  - 알림/푸시 시스템 완성
