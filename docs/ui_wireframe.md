
# UI Wireframe Spec

Last updated: 2026-02-19

## Layout

- Global search
- Decision summary
- Priority controls
- Offer table
- Insights

## Priority Controls

Users can set:

- Price importance
- Condition importance
- Shipping importance
- Trust importance

## Condition Levels

Selectable weighting:

- 최상 (Like New)
- 상 (Very Good)
- 중 (Good)
- 하 (Acceptable)

Users can:

- Require minimum condition
- Prefer better condition
- Trade price vs condition

## Fallback

If no used copy:

- Suggest new
- Respect price ceiling
- Notify option
