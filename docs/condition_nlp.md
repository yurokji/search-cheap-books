
# Condition Inference via NLP

Last updated: 2026-02-19

## Objective

Infer condition when seller descriptions are noisy.

## Pipeline

- Text normalization
- Keyword extraction
- Transformer classifier
- Confidence scoring

## Signals

- Highlighting
- Notes
- Wear
- Smell mentions
- Missing pages

## Output

- Condition class (최상/상/중/하)
- Confidence
